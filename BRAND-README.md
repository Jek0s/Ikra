# IKRA DeLuxe — преміальний магазин

## Запуск у IntelliJ IDEA

Открой **эту** папку `ikra-deluxe`, где лежит `package.json` (а не папку уровнем выше).

```bash
npm install
npm run dev
```

Сайт: http://localhost:5173/ · админка: http://localhost:5173/admin

## Логотип

`public/ikra-deluxe-logo.png` — круглая крышка, выделенная из присланного скриншота; фон по краям прозрачный. При получении оригинала в большем разрешении просто заменить этот PNG.

## Замена фотографий, цен и описаний

Без Supabase: зайти в `/admin`, открыть «Товари», выбрать редактирование, загрузить фото, изменить цену и описание. Это **локальный деморежим**: изменения видны только в том же браузере.

Для живого сайта подключить Supabase по инструкции `README.md`, исполнить `supabase/schema.sql`, создать пользователя в Supabase Auth и добавить его UUID в `admin_users` (SQL Editor, вручную от имени владельца проекта). После этого права RLS ограничивают запись и чтение заказов авторизованным администратором. Никогда не помещать `service_role` в Vite ENV.

## Внимание

Цены и товары сейчас **демонстрационные**. Доставка, реальные контакты, тексты и оферта требуют утверждения перед запуском. Изображения заглушек лежат в `public/products/`; будущие изображения можно менять из админки.

## Сборка

```bash
npm run build
```

Полученная папка `dist` размещается на статическом хостинге, с SPA fallback на `index.html` (для Apache пример `.htaccess` есть в public). Supabase используется отдельно.
