# Редактирование сайта

Откройте `/admin` и войдите с логином и паролем единственного администратора. Для локальной работы: `npm run db:local`, `npm run admin:local`, `npm run dev:cloudflare`. Ссылок на витрину в админке нет; логотип не выполняет переход.

- **Товари** — товары, цены, характеристики, фотографии и наличие.
- **Акції** — состав и стоимость наборов.
- **Замовлення** — покупатели, состав заказа и статус.
- **Розділи сайту** — шапка, бегущая строка, акционный баннер, главный экран, преимущества, тексты акций и каталога, история магазина, рекомендация, доставка, цитаты, отзывы, FAQ, Instagram, призыв к покупке и подвал.
- **Контакти** — общий телефон, Instagram, TikTok, Telegram и окно связи. Ссылки WhatsApp и Viber формируются из телефона.
- **Налаштування** — заголовок вкладки браузера, описание страницы и логотип.

Выберите раздел, измените поля и нажмите **Зберегти зміни**. Изображения можно загрузить или указать путь/HTTPS-ссылку. Записи FAQ, отзывов, цитат и бегущей строки можно добавлять, удалять и менять местами. Большинство блоков можно скрыть переключателем. Вкладка сайта, открытая в том же браузере, подхватит сохранённые настройки. Несохранённые изменения в предпросмотр не попадают.

Без базы данные хранятся в localStorage: они доступны в этом браузере и могут исчезнуть при очистке данных сайта. Опубликованной версии нужны Worker API и D1; редактирование доступно после входа владельца.

## Сохранение в D1

В опубликованном сайте все разделы, товары, акции и заказы сохраняются в Cloudflare D1. Доступ к редактированию защищён входом владельца. На открытой странице посетителя изменения появляются при возвращении на вкладку или в течение 30 секунд.

Изображения загружаются через Worker в Cloudinary. Локальные правки из браузера автоматически в D1 не переносятся. Секреты бота и ключи не помещаются в публичные настройки разделов.

Подключение и проверка: [ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md](./ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md).
