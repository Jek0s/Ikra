# IKRA DeLuxe

React + TypeScript: лендинг с каталогом, акционными наборами, корзиной и админкой `/admin`. Данные реального магазина — Cloudflare D1, API и размещение сайта — Workers, уведомления — Telegram, загрузка фотографий — Cloudinary Free.

**Пошаговый запуск:** [ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md](./ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md). Домен можно купить и подключить позже. Платный хостинг Hostinger не требуется.

Нужен Node.js 22.18+ (проверено на Node.js 24).

## Быстрый просмотр макета

```bash
npm install
npm run dev
```

`http://localhost:5173` — макет магазина с данными браузера. Вход в админку обязателен во всех режимах; для работы с ней используйте локальную D1 по инструкции ниже.

## Проверка с настоящим API и локальной D1

```bash
npm run db:local
npm run admin:local
npm run dev:cloudflare
```

`http://127.0.0.1:8787` — сайт, `/admin` — вход владельца. Логин единственного администратора и сгенерированный пароль задаются командой `admin:local`. Облачный аккаунт не нужен; D1 находится в `.wrangler/`. Telegram и Cloudinary подключаются секретами из `.dev.vars.example`.

## Проверки

```bash
npm test
npm run build
```

Тесты выполняются в локальном эмуляторе D1. Telegram и Cloudinary подменены: внешние сообщения и загрузки не выполняются.

## Публикация

После входа в Cloudflare, создания D1 и замены `database_id` в `wrangler.jsonc`:

```bash
npm run db:remote
npm run deploy
npm run admin:remote
```

Полная инструкция, настройка Telegram, фото и домена — в [руководстве](./ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md). Публикуются сайт и Worker вместе; отдельная загрузка `dist` на статический хостинг не подключает API.

Секреты хранятся только в Worker (локально — `.dev.vars`), не в `VITE_*`. У production-сборки нет обхода входа администратора. Цены заказа определяет сервер по каталогу D1. Заказы сохраняются до попытки отправить Telegram; при сбое отправка повторяется. Дневные лимиты бесплатных тарифов учитываются отдельно от размера каталога.

## Основные файлы

- `src/pages/HomePage.tsx` — витрина; `src/components/ProductCard.tsx` — карточка товара.
- `src/pages/AdminPage.tsx` — товары, акции, заказы, разделы, контакты и настройки.
- `src/lib/backend.ts`, `store.ts`, `offers.ts`, `site-content.ts` — клиент API и локальный деморежим.
- `worker/` — вход, валидация, Cloudinary, оформление заказа и доставка в Telegram.
- `migrations/` — структура D1 и первоначальный каталог; повторные миграции не затирают правки из админки.
- `wrangler.jsonc` — Worker, D1, статические файлы и расписание повторной отправки.
- `tests/worker.test.mjs` — интеграционные проверки.

Предыдущая схема Supabase в `supabase/` оставлена как архив; приложение её больше не использует. Локальные изменения из браузера в облако автоматически не импортируются. Онлайн-оплата и автоматическое создание накладных не подключены.
