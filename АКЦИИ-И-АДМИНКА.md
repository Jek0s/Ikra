# Акции и админка

В `/admin` → **Акції** можно добавлять, изменять, скрывать и удалять наборы, редактировать фотографии, цены и состав. Кнопка заказа на сайте добавляет набор в корзину.

- `npm run dev` — деморежим витрины: данные только в браузере; обхода входа в админку нет.
- `npm run dev:cloudflare` — сайт с API и локальной D1 (сначала `npm run db:local` и `npm run admin:local`).
- Опубликованный Worker — общая D1 для товаров, акций, заказов и настроек. Стоимость и доступность наборов проверяются сервером при оформлении заказа.

Для новых фото через админку нужен Cloudinary; существующие фото проекта работают сразу.

Подключение базы, Telegram, изображений и собственного домена: [ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md](./ПОДКЛЮЧЕНИЕ-CLOUDFLARE.md).
