# IKRA DeLuxe — Акции и админка

## Локальная проверка

1. Открой папку проекта в IntelliJ IDEA.
2. Запусти `npm install` и `npm run dev`.
3. Открой `/admin` (в режиме разработки без Supabase редактор доступен для локального тестирования).
4. Перейди во вкладку «Акції». Можно добавить, отредактировать, удалить или скрыть набор, поменять состав, описание, фотографию, акционную и старую цену.
5. Вернись на главную: акция появится в карусели. Кнопка «Замовити» добавит акционный набор в корзину. Локальное оформление заказа сохраняется в браузере.

## Важно перед публикацией клиенту

- Сейчас акции хранятся в **localStorage** (`ikra_deluxe_offers_v1`). Товары и заказы также имеют локальный режим. Это позволяет завершить дизайн без базы.
- На разных устройствах и в разных браузерах локальные изменения не синхронизируются. При очистке данных браузера они пропадут.
- Даже если Supabase подключён для основных товаров, **акции пока не сохраняются в Supabase**: перед передачей клиента нужно подключить их к выбранному реальному бэкенду (PHP + MySQL на Hostinger либо другая БД), а также серверно реализовать обработку заказов на наборы.
- Публичная production-версия без Supabase не открывает `/admin` до настройки защищённой авторизации.
- Для размещения магазина на Hostinger нужен сборочный `dist`; `npm run build` и затем загрузка содержимого `dist` на хостинг.
